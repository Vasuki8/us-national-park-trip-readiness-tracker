# U.S. National Park Trip Readiness Tracker

Independent, source-backed trip planning for U.S. national parks.

The owner approved the initial design on 2026-09-28 and authorized development in this repository. The first development branch will add the five-park pilot, tests, and handoff documentation. This initialization is not a live website or a claim of current park conditions.

Core constraints: light theme, no paid data dependencies, no safety score, truthful source/freshness labels, no active advertising or paid services during the pilot.
